A tiny Node program that writes one short text to `/output/entry.txt` — a single-line joke about office life. Ask HR for a raise, get a mindfulness app instead: the punchline lands in two words, "calmly underpaid". One sentence, specific detail, clear on first read. 87 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
